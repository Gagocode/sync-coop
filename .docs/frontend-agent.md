# Orientação de frontend para agentes — Sync-Coop

Leia agent.md, documento_mestre.md, documento_dominio.md, documento_tecnico.md e design-system.md. O frontend implementado é Flask/Jinja com HTML, CSS e JavaScript convencional; o dashboard atual é individual e legado. Não troque stack nem apresente telas corporativas como existentes sem código correspondente.

Em trabalho futuro, desenhe a experiência do colaborador como conjunto integrado de perfil, DISC, missões, prazos, evolução e atividade. Gestores, administradores e profissionais autorizados precisam de superfícies e permissões distintas. Antes de mostrar dado pessoal, confirme no backend organização, vínculo, papel e finalidade. A interface pode ocultar ações, mas não substitui autorização do servidor.

Mostre a origem e o período de indicadores; diferencie acesso, atividade qualificada e inferência. Não use DISC, XP ou inatividade como diagnóstico ou nota de desempenho. Apresente estados vazios e mensagens de erro sem fabricar dados. Preserve acessibilidade e a identidade visual atual até decisão de marca; padrões corporativos novos são pendentes.

Não implemente estados de missão, fórmulas, rankings, comparações ou sinais cuja regra esteja marcada como pendente em decisions.md. Mantenha contratos de rotas existentes até haver migração coordenada.
